# 02 Source Strategy

## Coverage priority
YouTube, Reddit, X, TikTok, Instagram, Facebook, Threads, forums/communities, public web discussions, and marketplace reviews where permitted. Academic databases and credible expert sources form separate evidence streams.

## Preferred access hierarchy
1. Official API.
2. Permitted public HTML.
3. Search-index discovery.
4. Approved data provider.

Never bypass authentication, CAPTCHA, robots rules, paywalls, or anti-bot controls.

## Source-specific strategy
**YouTube:** search Indonesian and global beginner, troubleshooting, setup, kit review, smart-hydroponic, and failure content; collect comment/reply metadata.

**Reddit:** discover relevant gardening/hydroponic/urban farming communities dynamically; preserve subreddit and thread context.

**X:** use valid current official API access. Do not fake historical coverage.

**TikTok:** use Research Tools only with legitimate eligible access. If unavailable, document the gap rather than bypassing.

**Instagram/Facebook/Threads:** prefer official Meta access and public content legitimately available under granted permissions; never scrape private groups.

**Forums:** prioritize hydroponic, urban-farming, gardening, and smart-farming discussions.

**Marketplace:** where public review collection is permitted, use for product quality, price complaints, setup difficulty, missing parts, reliability, shipping, and post-purchase signals.

**Articles:** use for context and expert commentary; do not count article text as customer comments.

## Coverage-quality score
Rate each source family using directness, provenance, volume, independence, temporal quality, geographic relevance, and demographic relevance.
