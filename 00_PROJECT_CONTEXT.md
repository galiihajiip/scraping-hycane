# 00 Project Context

## Origin
The team is developing HYCANE for BPC RISE 2026. The advisor requested stronger market/customer validation using real internet discourse, especially public comments and discussions, to understand interest, obstacles, pain points, and customer language.

## HYCANE
A proposed smart hydroponic ecosystem combining:
- sugarcane bagasse as biodegradable growing media;
- hydroponic cultivation;
- IoT sensing;
- real-time monitoring;
- AI-assisted analysis, anomaly detection, alerts, and recommendations;
- mobile app;
- education/community/customer support;
- recurring consumables and B2B/institution opportunities.

Core value chain: **bagasse waste -> biodegradable media -> hydroponic growth -> sensor data -> cloud/data layer -> AI analysis -> alerts/recommendations -> user action**.

## Existing market hypothesis
Current materials describe urban/semi-urban home growers and hydroponic beginners, roughly age 20-40, Indonesia with Java priority, middle-market positioning, technology interest, and sustainability interest. Secondary: communities, schools, universities. B2B hypothesis: urban farms, restaurants, hotels, agricultural SMEs, institutions. These are not validated facts until this study or primary research supports them.

## Competition
Theme: **From Vision to Venture: Membangun Bisnis yang Inovatif dan Berkelanjutan**. Selected subtheme: **Agroteknologi & Ketahanan Pangan**. The research strengthens the proposal's problem, customer, market, value proposition, marketing, validation, and BMC layers.

## Core thesis to test
Is HYCANE merely technologically interesting, or does it reduce a real and recurring friction people experience when trying to grow hydroponically?
