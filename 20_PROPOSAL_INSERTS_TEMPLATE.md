# 20 Proposal Inserts Template

Use this only after analysis is complete.

## Background evidence
Write:
`Within the observed public corpus of [n] records across [platform/source count], recurring hydroponic discourse centered on [themes]. The most frequent frictions were [pains], while positive discourse emphasized [benefits].`

Do not call it a population survey.

## Customer problem
Structure: `problem -> evidence -> consequence`.

## Persona
Structure: `who -> context -> jobs -> pain -> buying signal -> feature relevance`.

## Value proposition
Structure: `validated pain -> HYCANE response -> user outcome`. Do not promise guaranteed yields or autonomous cultivation unless separately validated.

## Marketing
Derive message, persona, channel, content topic, and CTA from observed language.

## BMC
State which block changes: Customer Segments, Value Proposition, Channels, Customer Relationships, Revenue Streams, Key Activities, Key Resources, Key Partners, Cost Structure.

## Validation
For uncertain findings define hypothesis, test, sample, metric, and decision rule.

## Citation discipline
Every number must point to a saved table/source. Social listening findings should be cited as study findings, not silently reframed as academic or population facts.
