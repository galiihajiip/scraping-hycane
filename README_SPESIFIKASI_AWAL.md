# HYCANE Social Listening & Customer Insight Research
## Claude Code End-to-End Research Pack

This project pack is designed for Claude Code to execute: source discovery -> public-data collection -> API/scraping ingestion -> raw archival -> cleaning -> normalization -> deduplication -> spam screening -> language detection -> sentiment -> topic discovery -> pain-point extraction -> customer intent -> persona clustering -> academic/expert triangulation -> visualization -> business insight -> HYCANE feature mapping -> proposal-ready evidence.

**Target:** minimum 5,000 unique real public comment/post records; preferred 10,000+; stretch 20,000+ where access, quota, and terms permit.

Never manufacture comments, labels, engagement, survey responses, quotes, or market statistics.

### Business context
HYCANE is a proposed smart hydroponic ecosystem combining sugarcane bagasse as biodegradable growing media, hydroponics, IoT sensing, real-time monitoring, AI-assisted analysis/recommendations, and a mobile application. The competition is BPC RISE 2026. Official theme: **From Vision to Venture: Membangun Bisnis yang Inovatif dan Berkelanjutan**. Selected subtheme: **Agroteknologi & Ketahanan Pangan**.

The advisor requested stronger evidence of whether people are interested in hydroponics, what prevents success, what frustrations recur, what they value, and what customer personas/features can be defended with real internet evidence.

### Core research logic
**Public discourse -> sentiment + topics + pain points + intent + behavior signals -> customer insight -> validation -> persona -> feature priorities -> business implications**

Do not equate positive sentiment with purchase intent, comment volume with market size, or social-media users with all Indonesian consumers.

### Deliverables
Raw immutable captures, normalized/cleaned gold dataset, data dictionary, source audit, collection logs, sentiment, topic/pain-point analysis, intent analysis, feature demand, persona clusters, academic/expert evidence, cross-platform comparisons, visualizations, dashboard, report, proposal-ready tables, HYCANE implications, limitations, validation plan, reproducibility, final QA manifest.

### Integrity
Public data only. No private content, CAPTCHA bypass, login bypass, anti-bot evasion, robots bypass, paywall bypass, or credential abuse. If a source is blocked, log the blocker and continue with permitted alternatives.

### Reading order
Read `CLAUDE.md` first, then all numbered MD files in order. Inspect all available HYCANE and RISE source documents before collection.
