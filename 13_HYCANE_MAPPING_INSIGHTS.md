# 13 Mapping Insights Back to HYCANE

## Core mapping
`observed discourse -> pain point -> customer job -> desired outcome -> HYCANE response -> business value -> proposal section`

## HYCANE response library
**Material:** bagasse-based biodegradable growing-media concept, waste valorization, circular-economy value.

**IoT:** pH, TDS/EC, temperature, water-level monitoring. Logic: uncertainty -> visibility -> timely action.

**AI:** anomaly detection, interpretation, alerts, recommendations, and potentially predictive cultivation later. Do not promise guaranteed yields or autonomous cultivation.

**App:** dashboard, alerts, guided cultivation, history, education, community, support.

## Feature prioritization
Score each candidate feature transparently on customer signal, pain severity, recurrence, cross-platform breadth, strategic fit, technical feasibility, and monetization fit. Keep explicit requests separate from inferred demand.

## Proposal impact table
Create:
`Finding | Evidence level | Current proposal statement | Recommended change | Proposal section`

## Message testing
Extract recurring user language as message territories, not final slogans. Test terms such as convenience, confidence, small-space usability, guided growing, monitoring, and sustainability only when supported by the corpus.

## Pricing
Use explicit price conversations, product comparisons, and buying language. Never infer a numeric willingness-to-pay from sentiment. Produce `outputs/pricing_research_gaps.md`.
